# Kiosk Requirements

1. View Movies and Showtimes --— The customer can browse a list of
   available movies and their showtimes.
2. Select a Seat --— The customer can choose an available seat for a
   selected showtime.
3. Purchase a Ticket --— The customer can complete payment and purchase
   a ticket for the selected seat.
4. Confirmation --— The system provides a confirmation (e.g., ticket
   number or receipt) once the purchase is complete.
5. Prevent Double-Selling --— The system must not allow the same seat to
   be sold to two different customers.
