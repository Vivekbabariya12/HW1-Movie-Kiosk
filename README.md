# Movie Theater Ticket Kiosk
This project is a guided exercise modeling a self-service movie theater kiosk.
Customers can browse movies and showtimes, select an available seat, and
purchase a ticket. The system confirms each purchase and ensures that no
seat is sold to more than one customer.

## Purpose

The purpose of this repository is to practice GitHub version control, requirements documentation, issue tracking, project management, and UML modeling.
## Expanded Use Case: Purchase Ticket

**Primary Actor:** Customer

**Precondition:** The customer has selected a movie and showtime, and tickets are available.

### Main Steps

1. The customer views available seats.
2. The customer selects an available seat.
3. The system checks the selected seat availability.
4. The customer confirms the ticket selection.
5. The customer provides payment information.
6. The system processes the payment.
7. The system creates the ticket.
8. The system displays the purchase confirmation.

**Postcondition:** The ticket is purchased, the selected seat is reserved, and the customer receives confirmation.
