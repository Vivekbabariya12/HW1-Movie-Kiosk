# Movie Theater Ticket Kiosk
This project is a guided exercise modeling a self-service movie theater kiosk.
Customers can browse movies and showtimes, select an available seat, and
purchase a ticket. The system confirms each purchase and ensures that no
seat is sold to more than one customer.

## Purpose

The purpose of this repository is to practice GitHub version control, requirements documentation, issue tracking, project management, and UML modeling.
